# Before changing repository visibility

This repository remains private until the author explicitly approves publication.

- [ ] Confirm the final manuscript title, author list and symposium/submission
  status; add the correct citation/DOI only when available.
- [ ] Choose an explicit software license after confirming contributor and
  institutional rights. No license has been assigned automatically.
- [ ] Review external method attributions in `docs/references/` and dataset
  download/licensing terms. Citation is not a substitute for a software license.
- [ ] Decide whether externally hosted checkpoints or reproduction artifacts
  may be released, and document permissions and hashes separately.
- [ ] Review all Git history for credentials, private local paths, raw images,
  feature arrays, checkpoints and prediction-level records.
- [ ] Verify package installation, core and optional tests, and the exact commands
  in the README on the intended public environment.
- [ ] Review the preserved scientific limitations; do not silently strengthen
  the historical claim of prospective locking or bitwise reproducibility.
- [ ] Confirm that the original private research archive remains separate.
- [ ] Obtain explicit author approval before switching to public visibility.

Until licensing is resolved, availability to collaborators does not grant a
general open-source redistribution license.
